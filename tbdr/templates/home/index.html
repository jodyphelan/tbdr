Analyse your data with TB-Profiler

Upload next generation sequencing data to detect drug resistance mutations and infer lineage of M. tuberculosis using the WHO v3 mutation catalogue.

Analyse a FASTQ file

How it works

  1. 1

    Upload

    Submit FASTQ files from one or multiple samples for analysis. Both Illumina and Oxford Nanopore Technologies data are supported.

  2. 2

    Processing

    Your genomic data is processed automatically using TB-Profiler with the WHO v3 mutation catalogue to generate a comprehensive report on drug resistance and lineage.

  3. 3

    Results

    Each sample is assigned a unique result ID, which you can use to access your results at any time.
